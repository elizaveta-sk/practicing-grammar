# Test set: follow-up questions

Answers to bank questions, to see which follow-up the app would ask: the first model's question, then the reviewer's (`lib/review-question.ts`). Not graded automatically, except that the final question must use the grammar and have at most 15 words. **Read the results** (`evals/results/followups.md`) and judge whether the questions are kind and sensible.

Run it with `npm run eval:followups`.
